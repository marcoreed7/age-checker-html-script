## What Age Checker Does

Age Checker is a compact browser example built around a basic age decision in JavaScript. It asks the visitor for an age and applies conditional logic to evaluate the entered value.

The project is intended as a practical introduction to HTML and JavaScript basics. It offers a clear example of browser prompts, `if/else` statements, and alert messages, while remaining easy to open, study, and adapt locally.

---

## Highlights

- Collects an age using a browser prompt.
- Identifies the entered result as adult or child.
- Shows how JavaScript `if/else` logic works.
- Reports the classification in a browser alert.
- Keeps the user interface in a simple HTML page.
- Works immediately in a standard web browser.
- Serves as a concise exercise for learning introductory JavaScript.
